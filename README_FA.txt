تیزرساز تاپینگ — خروجی واقعی MP4

۱) فایل ZIP را از حالت فشرده خارج کنید.
۲) FFmpeg و Python 3 باید روی کامپیوتر نصب باشند. در مک، اگر Homebrew دارید: brew install ffmpeg
۳) روی Start_Topping_Teaser.command دوبار کلیک کنید. اگر مک اجازه اجرا نداد، Terminal را در همین پوشه باز کنید و اجرا کنید:
   python3 Topping_Teaser_Server.py
۴) صفحه http://127.0.0.1:8765 باز می‌شود. عکس/ویدیو اضافه کنید، ترتیب و مدت هر صحنه را تعیین کنید و Create MP4 را بزنید.
۵) پس از اتمام پردازش، روی دکمه نارنجی Save MP4 کلیک کنید. فایل به پوشه دانلودهای مرورگر می‌رود.

لوگو در هدر هر فریم ثابت است و فوتر فقط آدرس سایت toppingcourier.ca را نشان می‌دهد. عکس یا ویدیو به‌صورت خودکار وسط کادر شبکه‌های اجتماعی جا می‌شود (پر کردن مرکز، بدون حاشیه خالی). صداهای ویدیوهای ورودی در خروجی حفظ می‌شوند؛ عکس‌ها بی‌صدا هستند.
این برنامه تنها به 127.0.0.1 گوش می‌دهد و فایل‌ها را به سرویس خارجی نمی‌فرستد. پنجره Terminal را تا پایان خروجی گرفتن باز نگه دارید؛ برای بستن برنامه Control+C را بزنید.
